Кілька історичних записів у колекції навмисно НЕ отримали окремого файлу — їхній
прапор фактично не відрізнявся від прапора сучасної країни-наступниці (перевірено
дослідженням для кожного): Веймарська республіка, Чехословаччина/ЧСФР, Польська
Народна Республіка, Мозамбік (Португальська колонія), Французька Західна Африка,
Франція (Режим Віші), Тайвань/Китайська Республіка (останній — з виправленням
маршрутизації в `countryUtils.ts`, оскільки раніше помилково показував прапор
материкового Китаю).
